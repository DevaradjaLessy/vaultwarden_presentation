# 20 minutes SI : la solution Vaultwarden

Formation de 20 minutes pour découvrir le coffre-fort de mots de passe, avec un parcours guidé du jour J.

| Fichier | Contenu |
|---|---|
| `index.html` | Le diaporama (s'ouvre sans réseau). Touches : → ou espace pour avancer, F plein écran, N notes, P vue présentateur |
| `maquettes/1-mail-invitation.html` | Début du parcours : le mail d'invitation, « Rejoindre Vaultwarden », la récupération du compte, « Et maintenant ? », puis l'application Bitwarden sur le bureau Windows |
| `diaporama-20-minutes-si.pdf` | Le diaporama en PDF, une diapo par page |

Les maquettes ne sont que des pages de démonstration : aucune donnée n'est envoyée. La phrase d'empreinte affichée est fictive.

## Publier avec GitHub Pages

1. Déposer le contenu de ce dossier dans un dépôt GitHub.
2. Dans le dépôt : Settings › Pages › Branch : `main`, dossier `/ (root)`.
3. Le diaporama est alors à l'adresse du site, et la démonstration à `…/maquettes/1-mail-invitation.html`.
